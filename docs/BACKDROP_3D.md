## สถานะ

ใช้งานได้ครบทุกส่วน ทดสอบบนจอคอม จอมือถือ (400px) และธีมสว่าง/มืดแล้ว ไม่มี error
คอมมิตทั้งหมดอยู่บนแบรนช์ `claude/vigilant-mendel-7905kw` และ push ขึ้น GitHub แล้ว
ล่าสุด `e26cbf7` — หลังแผงสีฟ้าล้วน · ปิดไฟ LED · จัดของตกแต่งเป็นจุด ①–⑥ · เอารายการของที่ต้องซื้อออก
หน้า artifact อัปเดตถึงเวอร์ชัน 12 แล้ว ตรงกับไฟล์ในรีโป

### สิ่งที่เจ้าของงานสั่งไว้ (อย่าทำกลับ)

- **ไม่เอาแผ่นรองหลังสีเหลือง** — `D.back` ปิดไว้ ไม่อยู่ในชุดสำเร็จรูปทั้งสองชุด
- **ไม่เอาจุดขาว ๆ ด้านบน** = ไฟหยดน้ำ LED — `D.lights` ปิดไว้ ไม่อยู่ในชุดสำเร็จรูป
  (เหลือเช็กบ็อกซ์ไว้ให้ติ๊กเองถ้าเปลี่ยนใจ)
- **ไม่เอารายการของที่ต้องซื้อ/ราคา** — ถอดการ์ดนั้นกับฟังก์ชัน `renderShopList()` ออกหมดแล้ว
- **ด้านหลังต้องเป็นสีฟ้าเหมือนฉากจริง** ห้ามปล่อยให้เห็นอาร์ตเวิร์กกลับด้าน
- **ของตกแต่งต้องมีที่อยู่ชัดเจน** ไม่ใช่โปรยมั่ว ๆ (ดูหัวข้อจุดตกแต่ง)

### สไตล์เนื้อหา 3 แบบ

1. **การ์ดขาว–ทอง** (`styleCard`) — การ์ดขาวแถบหัวข้อทองบนพื้นสีแผง เหมาะกับพิมพ์ไวนิลแผ่นเดียวจบ
2. **แผงวงจร** (`styleTech`) — พื้นเขียวเข้มลายเส้นวงจร หัวข้อเลขโมโน ธีมเดียวกับกระดานเกม
3. **A4 ตัดประกอบ** (`styleCutPaste`) — หน้าตาเหมือนสไตล์ 1 แต่ทุกชิ้นพิมพ์ A4 แล้วตัดมาต่อกัน
   สำหรับกรณีพิมพ์ได้แค่ A4 · ค่าเริ่มต้นได้ 17 แผ่น · บนแผงมีเส้นประบอกรอยต่อ

เนื้อหาทั้ง 3 สไตล์ดึงจากชุดเดียวกันที่ตัวแปร **`BOARD`** (ย่อจาก `docs/PROJECT_SUMMARY.md`)
แก้ข้อความที่เดียวมีผลทุกสไตล์

## จุดตกแต่ง ①–⑥

ของตกแต่งทุกอย่างถูกจัดให้ไปอยู่ 6 จุดนี้ ทั้งในแถบควบคุมและบนโมเดล (ติ๊ก "แสดงหมุดจุด ①–⑥")

| จุด | ของที่วาง | คีย์ใน `P.deco` |
|---|---|---|
| ① ยอดช่อกลาง | พู่กระดาษห้อย (อยู่ในช่วงยอดลาย ไม่ทับเนื้อหา) · เลื่อมขอบลาย · ไฟ LED | `tassel` `seqEdge` `lights` |
| ② รอยพับซ้าย–ขวา | เถาวัลย์พันแนวตั้งตามรอยพับแผงกลาง | `vineFold` |
| ③ กรอบการ์ด QR | เลื่อมล้อมกรอบการ์ด (อ้างตำแหน่งจาก `artworkCanvas().qr`) · ป้ายชื่อบูธ | `seqQR` `sign` |
| ④ ขอบล่างทั้ง 3 แผง | แถบลายกนกกระดาษทอง + เลื่อมเรียงสองแถวบนแถบ | `kanok` `seqStrip` |
| ⑤ มุมล่าง · ขอบข้าง | ดอกไม้กระดาษย่นมุมล่างแผงริม · เถาวัลย์ขอบข้าง · เทปกากเพชร · ธงราว | `flower` `vine` `edge` `bunting` |
| ⑥ โต๊ะหน้าบอร์ด | ผ้าปูโต๊ะ · กล่องเกม/การ์ด/ธนบัตรของจริง · โรยเลื่อมกลม | `props` `cloth` `seqTable` |

ค่าตั้งต้นที่เปิดไว้: `flower` `cloth` `kanok` `tassel` `props` `vine` `vineFold` `seqTable` `seqQR` `seqStrip`
ตำแหน่งการ์ด QR มาจากสไตล์เนื้อหาเอง (`G.qr` ที่ `styleCard` / `styleTech` / `styleCutPaste` เซ็ตไว้)
เป็นพิกัดอาร์ตเวิร์ก (y ชี้ลงจากขอบบนแผง) ต้องแปลงเป็นพิกัดแผงด้วย `y_แผง = hTot - y - h`

### หลักการที่ต้องรู้ก่อนแก้

**ลายไทยไม่ใช่รูป แต่เป็นเส้นตัดจริง**
`drawPanel()` วาดลายลงแคนวาส (ตัวกนกคือริบบิ้นเรียวที่ม้วนปลาย ด้านท้องอวบกว่าด้านหลัง
ปลายจึงแหลม) แล้ว `contoursFromField()` ไล่ขอบด้วย **marching squares** ที่ระดับ alpha 0.5
ได้เส้นปิดเป็น มม. → `rdp()` ลดจุด → จัดชั้นคู่/คี่เป็นชิ้นงาน/รูเจาะ → `ExtrudeGeometry`
ผลคือรูเจาะในโมเดลกับในไฟล์ตัดเป็นเส้นเดียวกันเสมอ ไม่มีทางหลุดจากกัน

**อาร์ตเวิร์กแปะเป็น texture ได้เพราะ UV ของ ExtrudeGeometry = พิกัดมิลลิเมตรตรง ๆ**
`panelMat()` จึงตั้ง `texture.repeat = (1/กว้าง, 1/สูง)` แล้วภาพลงตำแหน่งพอดีโดยไม่ต้องทำ UV เอง
สีพื้นแผงถูก "อบ" ลงในแคนวาสอาร์ตเวิร์ก เปลี่ยนสีวัสดุจึงต้องสร้าง texture ใหม่ (`applyMats()`)

**ของตกแต่งเกาะไปกับแผง**
ชิ้นที่ต้องพับตามแผง (แผ่นรองหลัง เทปกากเพชร ไฟ ป้าย ดอกไม้ ขอบกนก พู่ เถาวัลย์ขอบข้าง/รอยพับ
เลื่อมรอบ QR เลื่อมบนแถบกนก เลื่อมขอบลาย) เป็นลูกของ mesh แผงนั้น
ส่วนชิ้นที่พาดข้ามแผง (ธงราว เถาวัลย์ด้านบน เลื่อมบนโต๊ะ ของจริงจากเกม)
อยู่ใน `decoWorld` ซึ่งคำนวณตำแหน่งจากมุมพับเอง
ชิ้นที่ buildDeco สร้าง geometry ขึ้นเองต้องปัก `userData.own = true` ไว้ จะได้ถูก dispose ตอนสร้างรอบใหม่

**ด้านหลังแผงต้องมีแผ่นปิด**
ฝาหลังของ `ExtrudeGeometry` ใช้ UV ชุดเดียวกับด้านหน้า ถ้าปล่อยไว้จะเห็นอาร์ตเวิร์กกลับด้านเวลาหมุนไปดูข้างหลัง
`buildDeco()` จึงแปะ `ShapeGeometry` รูปเดียวกับแผง (เจาะรูด้วย) ที่ `z = -0.15` ด้วย `backMat`
ซึ่งเป็น `side: BackSide` สีวัสดุล้วน — `applyMats()` เป็นคนอัปเดตสีกับความเงาให้

**จุดวางของตกแต่งอยู่ที่ `SPOT_PLAN`**
ตารางเดียวคุมทั้งรายการในแถบควบคุมและหมุดเลขในฉาก แต่ละแถวคือ
`[เลขจุด, ชื่อจุด, คำอธิบาย, คีย์ใน P.deco ที่เกี่ยวข้อง]` — เพิ่มของตกแต่งใหม่ให้ผูกเข้ากับจุดด้วย

**ไฟล์นี้เป็นทั้งไฟล์ในเครื่องและหน้า artifact**
ส่วนที่อยู่ระหว่าง `<!--ARTIFACT-START-->` ถึง `<!--ARTIFACT-END-->` คือเนื้อที่ตัดไปเผยแพร่
(ข้างนอกมีแค่ doctype/charset/viewport ที่หน้า artifact ใส่ให้เองอยู่แล้ว)
วิธีอัปเดตหน้าเว็บหลังแก้ไฟล์:

```bash
# ตัดช่วงระหว่างมาร์กเกอร์ออกมาเป็นไฟล์ artifact
awk '/ARTIFACT-START/{f=1;next}/ARTIFACT-END/{f=0}f' tools/backdrop_3d.html > /tmp/art.html
```

แล้ว publish ไฟล์นั้นทับ URL เดิม (ต้อง `read` artifact ก่อน publish ถ้าเป็นเซสชันใหม่)
ประกาศ capability ไว้แค่ `downloads`

## กับดักที่เคยเจอมาแล้ว (อย่าพลาดซ้ำ)

- **`TubeGeometry` ต้องรับ segment เป็นจำนวนเต็ม** — ส่งทศนิยมเข้าไปจะพังที่ `generateSegment`
- **ฟอนต์โมโนไม่มีสระไทย** — ใช้ IBM Plex Mono ได้เฉพาะตัวเลข/อังกฤษ ภาษาไทยต้อง Kanit/Sarabun
- **น้ำหนักฟอนต์ที่โหลดไว้** Kanit 500/600/800 · Sarabun 400/500/600 · Plex Mono 400/500 เท่านั้น
- **หน้า artifact บล็อกลิงก์ดาวน์โหลด** จึงต้องผ่าน `claude.use('downloads')` และนามสกุลที่อนุญาต
  มีแค่บางชนิด (`.html` `.svg` ได้ ส่วน `.dxf` `.obj` ไม่ได้ → ให้กดคัดลอกโค้ดแทน)
- **บนจอแคบปุ่มอยู่ใต้เวทีโมเดล** กดแล้วภาพเปลี่ยนนอกจอ เลยต้องเลื่อนจอไปให้ (`showStage()`)
- **ความกว้างลายขั้นต่ำ `MINW = 7` มม.** กันยอดลายเปราะหักตอนตัดเลเซอร์ อย่าลดลงกว่านี้
- **เช็กบ็อกซ์ของตกแต่งผูกจาก `DECO_IDS` ตัวเดียว** อย่าไล่ผูกมือทีละตัว (เคยลืมผูก 3 ตัวมาแล้ว)
- **ของตกแต่งต้องไม่ทับเนื้อหา** พู่ห้อยอยู่ในช่วงยอดลาย เลื่อมล้อมอยู่นอกกรอบการ์ด QR
- เปลี่ยนขนาด/ลาย = ต้องไล่ขอบใหม่ (หนัก) จึง debounce ไว้ ส่วนมุมพับ/สี/ความหนาเปลี่ยนทันที

## งานที่ทำต่อได้

- สไตล์เนื้อหาแบบที่ 4 (เช่น กระดาษสา/ไทยประยุกต์ หรือมินิมอลขาวล้วน)
- ให้ผู้ใช้แก้ข้อความทุกช่องในหน้าเว็บ (ตอนนี้แก้ได้แค่ชื่อบอร์ดกับบรรทัดผู้จัดทำ
  ที่เหลือแก้ที่ตัวแปร `BOARD`)
- ผังประกอบ (assembly map) หน้าแรกของไฟล์พิมพ์ A4 ว่าชิ้นไหนไปตรงไหน
- ไฟล์ตัดแยกเลเยอร์ (เส้นตัดนอก / รูเจาะ) สำหรับโรงงานที่ขอแยก
- ของตกแต่งเพิ่ม เช่น ไฟเส้นนีออนเดินขอบ · โมบายห้อย · กรอบโฟมนูน
- ย้ายป้ายชื่อบูธ (`D.sign`) ไม่ให้ทับการ์ด QR ตอนเปิดชุด “จัดเต็ม”
