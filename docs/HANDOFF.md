## การตัดสินใจของ user
- **จบเกม 2 แบบ** เลือกก่อนเล่น: กำหนดรอบ (10/12/15) → คะแนนรวมสูงสุดชนะ · หรือ เล่นจนล้มละลายเหลือคนเดียว → คนสุดท้ายชนะ · คนล้มออกจากเกม ที่เหลือเล่นต่อ
- **Crash Round ×2 ทั้งหมด** — ค่าเช่า + รางวัล (GO, เหตุการณ์บวก, โบนัส Bug Jam, กองกลาง Meltdown, Debug Rescue); ค่าปรับ/ค่าธรรมเนียม/ค่าเข้าด่านไม่คูณ · การ์ดกู้ระบบขั้นสุด = +1,000/คน (−200 ไม่คูณ) · การ์ดพิมพ์ยังเขียนแค่ค่าเช่า ต้องแก้ตอนพิมพ์รอบหน้า
- **ทอยเบิ้ล 3 ครั้งติดกัน = ไม่เดินครั้งที่ 3 ย้ายไปช่องติดบั๊กทันที ไม่ได้เงินเดือน จบตา**
- **ตัดระบบแต้มความรู้ทิ้ง** — คะแนนรวม = เงินสด + มูลค่าทรัพย์สิน (ราคาซื้อ + ครึ่งค่าอัปเกรด) · เสมอ = เงินสดมากกว่าชนะ
  (เหตุผล: จำลอง 4,000 เกม อัตรา 50 ₮ เปลี่ยนผู้ชนะแค่ 3.5%; เงินให้รางวัลความรู้อยู่แล้ว — คนตอบถูก 90% ชนะ 40% vs ดวงล้วน 25%)
