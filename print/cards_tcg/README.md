# การ์ดทรัพย์สินแนว TCG — เวอร์ชันปัจจุบัน (13 พ.ย. 2026)

ดีไซน์ด้านหน้าการ์ดทรัพย์สิน 16 ใบ ขนาด 63 × 88 มม. — กรอบแบบ **A2** + ภาพประกอบ 3 มิติ 1 ภาพต่อใบ (แผ่นหลัง + ของหลักตัวนูน + ป้ายคำลอย สีตามโซน)

**ดูภาพรวม:** `concept_13_all16.png` (หรือเปิด `concept.html?sheet=13`)

## ไฟล์ส่งพิมพ์ — `final/`

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `CodeCoin_การ์ดทรัพย์สิน_หน้า+หลัง.pdf` | พิมพ์สองหน้าอัตโนมัติ (6 หน้า สลับหน้า-หลัง) — ตั้ง **กลับด้านขอบยาว** |
| `CodeCoin_การ์ดทรัพย์สิน_หน้า.pdf` / `…_หลัง.pdf` | ร้านที่ขอไฟล์แยกด้าน หรือพิมพ์ทีละด้าน |
| `preview_front_1.png` / `preview_back_1.png` | ภาพตัวอย่างหน้าแรก |

- A4 แนวตั้ง 6 ใบ/หน้า · การ์ด 63 × 88 มม. + ตัดตก 3 มม. · ตัดตามเครื่องหมายตัดรอบนอก · **พิมพ์ 100% ห้ามย่อพอดีหน้า**
- ตัวหนังสือฝังฟอนต์ในไฟล์ (ไม่ได้แปลงเป็นเส้น) · สี RGB
- ยังไม่ได้พิมพ์ลองสแกน QR บนกระดาษจริง — ควรลอง 1 แผ่นก่อนพิมพ์ทั้งชุด
- ด้านหลัง (`concept_14_back.png`) จัดใหม่ให้เข้าชุดด้านหน้า ข้อมูลเท่าเดิม
- ไฟล์ REV 3.1 เดิมยังอยู่ที่ `print/Final/` ไม่ถูกแก้

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `concept.html` | ต้นแบบทุกแผ่นในไฟล์เดียว (`?sheet=1…13`) — แผ่น 13 = เวอร์ชันปัจจุบัน · ข้อมูลการ์ดอยู่ใน `const C` (คัดจาก `data.json` + คำสำคัญ REV 3.1) |
| `concept_13_all16.png` | ภาพรวม 16 ใบ เวอร์ชันปัจจุบัน |
| `img/art_<id>.jpg` | ภาพประกอบประจำใบ 1320 × 800 (ใช้ในกรอบ A2) · `art_<id>_hero.png` = เฉพาะวัตถุ พื้นโปร่ง |
| `concept_1…12_*.png`, `v1_vector/`, `img/styles/`, `img/art_coding_01b…r*` | ต้นแบบ / การทดลองรอบก่อน เก็บไว้อ้างอิง ไม่ใช้แล้ว |

## สร้างใหม่

```
py scripts/build_card_art.py [--draft] [id ...]   # ภาพประกอบ (ต้องมี Blender 5.x) ร่าง ~6 วิ/ใบ จริง ~1-2 นาที/ใบ
py scripts/render_cards_tcg.py 13                 # แผ่นรวม (ต้องมี Edge + pymupdf + ต่อเน็ตโหลดฟอนต์)
py scripts/build_cards.py                         # ไฟล์ส่งพิมพ์ final/ (ต้องมี opencv-python เพิ่ม) ตรวจข้อมูล ฟอนต์ QR ให้ก่อนเขียนไฟล์
```

รายละเอียด ประวัติการตัดสินใจ และข้อควรระวัง: `docs/HANDOFF_cards.md`
